# Contributing to Arcane Ledger

Thanks for helping improve Arcane Ledger. You can report bugs or suggest features without accepting the CLA.

## Contributor License Agreement

The [Individual Contributor License Agreement](CLA.md) gives Yuriy Pyrih, Creator and lead maintainer of Arcane Ledger, permission to use and license your original code as part of the project. You keep the copyright in your work.

After the CLA is adopted, you'll only need to accept it once, before your first code merge. To accept, read the CLA and post this comment from your own GitHub account in the **Conversation** tab of your first code pull request.

> I agree to the Arcane Ledger Individual Contributor License Agreement, version 1.0.

Acceptance covers original code in that pull request and later original code you intentionally submit for inclusion. For a shared pull request, anyone contributing original code who hasn't accepted yet follows the same steps before the merge. Please list any third-party material and its license in the pull request.

Before merging, Yuriy saves a private copy of each acceptance comment outside the repository, along with the comment link, the contributor's GitHub username and account ID, the acceptance date and time from the comment timestamp, and the CLA version and commit permalink. He checks this record on later pull requests.
